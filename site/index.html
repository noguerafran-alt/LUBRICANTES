Cómo usar la API

Todas las rutas /api/* piden la clave en el header X-API-Key (o Basic Auth, contraseña = clave). Nunca en la URL. Agregá ?formato=csv para CSV. Rutas: servicios, grok?mes=AAAA-MM, productos, equivalencias, ultimo, obs?mes=AAAA-MM, serie?p=producto_id, indice, fuentes, sin_match, oferta_ml.

Python sin dependencias:

import csv, io, os, urllib.request

req = urllib.request.Request("/api/ultimo?formato=csv",
                             headers={"X-API-Key": os.environ["LUB_CLAVE"]})
with urllib.request.urlopen(req) as r:
    filas = list(csv.DictReader(io.TextIOWrapper(r, encoding="utf-8")))
print(filas[0])
