Servicios (combos)

Precio de servicios cargados por Grok (cambio de aceite con mano de obra, etc.). Si el combo es solo aceite + colocación, se muestra su $/L (precio ÷ litros, con la mano de obra adentro); con filtros u otro repuesto no se divide. No entran al comparador ni al índice.

Mediana diaria de $/L por fuente. Un día sin dato corta la línea: no se arrastra el precio anterior.

Mediana de $/L de cada marca dividida por la de YPF, mismo segmento, SAE y día, × 100. 110 = 10 % más caro por litro que YPF. Sin YPF ese día no se calcula. Debajo de cada valor, los últimos 90 días. Las fuentes mayoristas (precio por caja o tambor, IVA no verificado) no entran; en la API se suman con ?mayoristas=1.

Cómo usar la API

Todas las rutas /api/* piden la clave en el header X-API-Key (o Basic Auth, contraseña = clave). Nunca en la URL. Agregá ?formato=csv para CSV. Rutas: servicios, grok?mes=AAAA-MM, productos, equivalencias, ultimo, obs?mes=AAAA-MM, serie?p=producto_id, indice, fuentes, sin_match, oferta_ml.

Python sin dependencias:

import csv, io, os, urllib.request

req = urllib.request.Request("/api/ultimo?formato=csv",
                             headers={"X-API-Key": os.environ["LUB_CLAVE"]})
with urllib.request.urlopen(req) as r:
    filas = list(csv.DictReader(io.TextIOWrapper(r, encoding="utf-8")))
print(filas[0])
